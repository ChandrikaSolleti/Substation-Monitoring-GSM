# Substation-Monitoring-GSM
Microcontroller-based substation monitoring and control system using GSM communication for real-time electrical parameter monitoring and protection. This project presents a microcontroller-based system for remote monitoring and control of electrical parameters in a substation.

The system monitors key electrical parameters including voltage, current, frequency, and temperature. The measured values are processed by a microcontroller and transmitted remotely using a GSM modem, allowing authorized users to monitor the substation without being physically present.

A relay-based protection mechanism is incorporated to respond when monitored parameters exceed predefined limits. The system can automatically generate SMS alerts during abnormal conditions and receive commands remotely for monitoring and control.

The prototype integrates sensing, display, communication, and protection components into a single embedded monitoring system. The project demonstrates the use of embedded systems and GSM communication for improving substation monitoring, protection, and continuity of supply.

## Tools & Technologies

### Hardware

- Arduino Uno / ATmega328P Microcontroller
- Current Transformer (CT)
- GSM Modem (SIM800)
- LM35 Temperature Sensor
- SPDT Relay
- 16×2 LCD Display
- Rectifier
- Crystal Oscillator

### Software

- Arduino IDE
- Embedded C/C++
- PIC C Compiler
- Proteus

### Communication

- GSM / SMS Communication
- Serial Communication

## Results

The developed prototype demonstrated the ability to:

- Monitor voltage, current, frequency, and temperature parameters
- Display monitored parameters through an LCD interface
- Transmit electrical parameters using GSM communication
- Generate SMS alerts when predefined parameter limits are exceeded
- Activate a relay as a protective response to abnormal electrical conditions
- Support remote monitoring and control of the substation system

The project demonstrates how embedded systems and GSM-based communication can be integrated to provide remote visibility and automated protection for electrical substations.
